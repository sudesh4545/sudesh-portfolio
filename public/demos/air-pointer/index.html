COMPUTER VISION · INTERACTIVE DEMO

Your hand. Your cursor.

Try the hand-tracking engine in your browser. Point to move the cursor; pinch your thumb and index finger to hit targets. The Windows app also controls the system mouse, dragging and scrolling.

Point → move · Pinch → click

Camera frames are processed locally, never uploaded. The tracking library and model download when you press Start. This browser demo moves the on-page cursor; system mouse control runs in the Windows desktop app. Press Escape to stop the camera.

Run the complete Windows app

Download the source from GitHub, install Node.js, then run npm ci and npm start inside the downloaded project folder. Create the Windows installer with npm run dist:win.
